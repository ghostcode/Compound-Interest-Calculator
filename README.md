## 简介

Compounder 是一个纯前端的复利计算器，支持初始本金、每月定投、多种复利频率等参数配置，通过实时图表和年度明细表，帮助用户直观理解复利效应如何随时间增长资产。

打开 HTML 文件即可使用，无需安装、无需构建、无需后端。

---

## 功能特性

### 核心计算

- **初始本金**：支持 0 ~ 500 万，输入框与滑块双向联动
- **年化收益率**：0% ~ 30%，0.1% 步进精细调节
- **投资年限**：1 ~ 50 年
- **每月定投**：0 ~ 10 万，模拟定期定额投入
- **复利频率**：每年 / 每半年 / 每季 / 每月复利

### 数据展示

| 模块 | 说明 |
|------|------|
| **指标卡片** | 最终总额、总投入、总收益、收益倍数四项核心指标 |
| **占比条** | 本金 vs 收益的可视化比例，实时更新 |
| **增长曲线** | 支持「面积图 / 柱状图」两种模式切换，hover 查看精确数值 |
| **年度明细表** | 逐年展示期初余额、本年投入、本年收益、期末余额、累计收益率 |

### 交互细节

- 所有参数变化**实时计算**，无需点击按钮
- 数字输入自动千分位格式化（如 `100,000`）
- 数值变化时微弹跳动画反馈
- 图表 tooltip 跟随鼠标显示详细数据
- 明细表可展开 / 收起，表头固定滚动
- 完整的键盘无障碍支持

## 复利公式

本计算器采用的复利公式为：

```
FV = P × (1 + r/n)^(n×t) + PMT × [((1 + r/n)^(n×t) - 1) / (r/n)]
```

其中：

| 符号 | 含义 |
|------|------|
| `FV` | 终值（最终资产总额） |
| `P` | 初始本金 |
| `r` | 年化利率 |
| `n` | 每年复利次数 |
| `t` | 投资年限 |
| `PMT` | 每期定投金额（按复利周期换算） |

定投部分的每期投入额通过 `每月定投 × (12/n)` 转换为与复利周期匹配的金额。

## 设计理念

- **深色金融主题**：深蓝黑底色搭配琥珀金强调色，传达专业、沉稳的理财氛围
- **收益即反馈**：翡翠绿标识所有收益相关数据，形成"绿色=增长"的直觉映射
- **渐进式信息展示**：核心指标 → 占比条 → 图表 → 明细表，从概览到细节层层深入
- **零门槛操作**：默认预填一组合理参数（10万本金、8%收益率、20年、月投2000），打开即有完整结果
